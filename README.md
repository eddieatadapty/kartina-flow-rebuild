# Kartina.TV Growth Audit

**Live → https://eddieatadapty.github.io/kartina-flow-rebuild/**

Five ideas to turn more Kartina.TV users into subscribers, each built into a clickable version of Kartina.TV's own onboarding. Prepared by Adapty.

| # | Idea | Potential outcome |
| :-- | :-- | :-- |
| 01 | Ask what they came to watch, then show it back | +10–20% CR to purchase |
| 02 | Let them press play before they pay | +5–15% CR to purchase |
| 03 | Make the free period predictable | +5–10% trial starts |
| 04 | Make the yearly saving impossible to miss | +5–15% ARPU |
| 05 | Offer Mobile to people who close the paywall | +5–10% CR from paywall closers |

Every price, rating and feature comes from Kartina.TV's App Store listing, website or in-app screens. Impact ranges are Adapty’s expected effect from teardowns and A/B tests across 30,000+ subscription apps, not measured lift for Kartina.TV. They overlap, so they don’t add up.

Static single page, no build step: `python3 -m http.server`.
